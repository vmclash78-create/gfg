# Production workflow

- Brief: exact spelling, offer, audience, positioning, restrictions and placements.
- Research: authorized reference material and category conventions; no imitation.
- Concept: 8–12 quick ideas, then three distinct routes.
- Build: simple SVGs with explicit viewBox and clean geometry.
- Audit: run svg_audit.py and treat findings as prompts for review, not truth.
- Preview: generate an HTML test sheet and inspect it in a browser.
- Checkpoint: ask the user to select or request revisions before making a complete kit.
- Craft: refine letterforms, optical balance, contrast and minimum size.
- Handoff: provide actual files, palette, typography/licensing notes and limitations.

Automated checks do not establish brand strategy, originality, accessibility in every context or legal clearance.
