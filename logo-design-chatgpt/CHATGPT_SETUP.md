# Use this skill in ChatGPT

GitHub is the storage location for these instructions; it does not automatically activate them in ChatGPT.

## Option A — ChatGPT Project

1. Open ChatGPT and create a Project for brand/logo design.
2. Open the Project's instructions/settings.
3. Copy the complete contents of `SKILL.md` into the instructions field.
4. Keep this repository's checklist and brief template available as project files if your interface supports file uploads.
5. Start a chat in that Project and describe the brand.

## Option B — Custom GPT

1. Open the GPT builder, if available on your plan/account.
2. Create a GPT focused on logo and brand identity design.
3. Paste `SKILL.md` into its Instructions field.
4. Add the checklist and brief template as knowledge files if supported.
5. Test it with a new-logo brief, a critique, and a redesign request.

## Option C — Use in a normal conversation

Open the `SKILL.md` file on GitHub, copy its contents, and paste it into a conversation with a request such as: "Use the following design process for this logo project."

## What this does and does not do

- It provides a reusable design process and response standard.
- It does not change the base ChatGPT model or permanently activate itself across every conversation.
- It does not grant ChatGPT automatic access to the repository or run local Python scripts.
- Automated SVG rendering, visual regression tests, and catalog search require tools/runtime support beyond prompt instructions.
